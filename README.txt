HAZRA BARI VIRTUAL DUAL TEMPLE — GITHUB UPDATE

Files in this package:
- app.py: Streamlit app with dual-temple Darshan and existing temple features, plus PostgreSQL compatibility fixes.
- requirements.txt: Streamlit, Astral, and psycopg dependencies.
- mahadev_shiva.png: Lord Shiva image; filename matches the path expected by app.py.

Upload all three files to the ROOT of the GitHub repository, in the same directory as app.py. Keep the repository's Streamlit entry point set to app.py. Commit to the branch used by Streamlit Cloud (usually main), then reboot the app.

IMPORTANT: This package does not modify or reset the Neon database. Do not delete existing database tables or user data.
